# boosthex

Boost URLs and hex query parts with stable normalization.

**Site:** https://theworker02.github.io/boosthex/

## Install / run

```bash
git clone https://github.com/theworker02/boosthex.git
cd boosthex
node src/cli.js
node --test
```
